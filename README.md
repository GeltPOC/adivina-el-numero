# Adivina el Número

Juego interactivo donde la computadora elige un número aleatorio entre 1 y 100 y el usuario intenta adivinarlo con pistas.

## Características

- Número aleatorio entre 1 y 100
- Pistas de "muy alto" o "muy bajo"
- Contador de intentos
- Historial de intentos
- Animaciones con Tailwind CSS
- Reinicio de partida

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
